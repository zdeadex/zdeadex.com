What it does

Ctrl’s site describes a crypto wallet with support for 2,500+ blockchains, and says Ctrl (formerly XDEFI) was founded in 2020.

The same page says that on August 19, 2026, Ctrl Wallet was permanently shut down, and that funds stay accessible by importing the recovery phrase into a compatible wallet.

Key features

  • 2,500+ blockchains, as stated on the site
  • Portfolio overview
  • Hardware wallet support — the site names Ledger and Trezor
  • Malicious address alerts
  • The site says it does not record user IP addresses
