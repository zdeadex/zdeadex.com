What it does

Staking platform: frontend (React + Vite) and backend (AdonisJS), multi-chain.

The public site says “Stake and get rewarded on the most secured and powerful staking platform.” It describes StakeLab as secure infrastructure that provides validating and relaying services for Proof of Stake blockchains, and lists networks, a rewards calculator, and staking.

Key features

  • Networks and staking
  • Rewards calculator
  • Validating and relaying services for Proof of Stake blockchains, as described on the site

What was implemented

  • Monorepo: frontend (Vite + React) + backend (AdonisJS)
  • WebSocket + REST API
  • Multi-chain: Cosmos (CosmJS, Cosmos Kit), Starknet, EVM (Wagmi/Viem)

Stack

TypeScript React Vite Node.js AdonisJS
