What it does

DeFi exchange platform: swap, bridge, perps API, referral system.

The homepage says “One app for all markets” and “Trade crypto, equities, FX, and commodities from one place.”

The site describes Junction as a cross-chain DeFi exchange that unifies liquidity from 1inch, LiFi, Morpho, Hyperliquid, and native bridges behind one REST API, GraphQL gateway, TypeScript SDK, embeddable widget, and MCP server. It lists same-chain and cross-chain swaps, one-call bridges, Hyperliquid perpetual futures, Morpho lending vaults, validator staking, and fiat on-ramp, across Ethereum, Arbitrum, Optimism, Base, Polygon, BSC, Avalanche, Solana, and Hyperliquid L1.

Key features

  • Smart-routed swaps and one-call bridges
  • Hyperliquid perpetual futures
  • Morpho lending vaults and validator staking
  • Fiat on-ramp
  • REST API, GraphQL gateway, TypeScript SDK, embeddable widget, and MCP server

What was implemented

  • Perps API (Express + TypeScript)
  • Front-end (JunctionCode: gateway, junction-front-end)
  • Assets, balances, fees, routing, chains registry, CoinGecko proxy
  • Referral & invite system

Stack

TypeScript JavaScript React Vite Node.js
